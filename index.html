Affordable Window Systems · Florida Home ServicesCRM + OPERATIONS REBUILD

Replacing a fragmented legacy CRM with a connected operating system

The business was moving away from MarketSharp and needed more than a database replacement. Sales, production, reporting, follow-up, data quality, and handoff logic all needed to work together.

THE PROBLEM

Fragmented workflows, duplicated records, limited reporting visibility, migration risk, and operational knowledge spread across people and tools.

WHAT I BUILT

Three core GoHighLevel pipelines, automated workflow logic, consent controls, duplicate suppression, Google Sheets and Apps Script data flows, Python QA checks, dashboards, and an 87-step onboarding SOP.

THE RESULT

A more centralized operating system for sales and post-contract work, with repeatable reporting and clearer handoff documentation for the team.

Stripe → Make → Zoho CRMINTEGRATION

Turning subscription events into reliable CRM updates

Problem

Subscription changes needed to update the correct customer tier without leaving stale tags or requiring manual CRM cleanup.

System

Event-based routing for subscription created, updated, and deleted events. The flow derives the plan, updates Zoho, removes old tiers, applies the correct tier, and handles cancellations.

Outcome

Correct tier tagging became automatic, giving the CRM a cleaner subscription state to work from.
